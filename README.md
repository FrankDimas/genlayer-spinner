# GenLayer Spinner

Original animated loading spinner designed with GenLayer brand identity.

## Live Demo

**https://frankdimas.github.io/genlayer-spinner/**

The demo shows the spinner running on both dark and light backgrounds.

## Features

- Smooth infinite animation loop
- Works on light and dark backgrounds
- Readable at small sizes
- Uses GenLayer Kinetic Cobalt (`#110FFF`)
- Geometry inspired by the official GenLayer mark
- Pure SVG + CSS (no dependencies)

## Files

- `index.html` — live demo page with the spinner
- `spinner.svg` — standalone spinner file
